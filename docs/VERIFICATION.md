## สรุปบั๊กที่พบและการแก้ไข

1. **การเปิดดูตัวอย่างบทความของแอดมิน (`?preview=1`) ในแท็บใหม่ทำให้ยอดวิวถูกนับเพิ่ม (`backend/src/routes/public.js`)**
   - **สาเหตุ:** ปุ่ม "ดูตัวอย่าง" ในหน้าจัดการบทความ (`/admin/articles`) เปิดลิงก์ `/articles/:id?preview=1` ด้วย `target="_blank"` ในแท็บใหม่ ซึ่ง `sessionStorage` ที่เก็บ `ict-admin-token` ไม่ถูกส่งต่อไปยังแท็บใหม่ ทำให้คำขอ `GET /api/articles/:id?preview=1` ไม่มี Header `Authorization` และถูกนับยอดวิวเหมือนผู้ใช้ทั่วไป
   - **การแก้ไข:** ปรับ `GET /api/articles/:id` ใน `backend/src/routes/public.js` ให้ข้ามการนับยอดเข้าชม (`skipCount = true`) ทันทีเมื่อคำขอระบุ `preview=1` หรือ Header `x-admin-preview: 1` โดยไม่ต้องย้าย Admin JWT ไปเก็บใน `localStorage` หรือแนบใน URL (ปลอดภัยและไม่เปิดเผยข้อมูลลับ เนื่องจากเส้นทางนี้แสดงเฉพาะบทความสถานะ `PUBLISHED` เท่านั้น)
2. **การปรับแต่งค่าตามข้อกำหนดของหน่วยงาน (`backend/src/server.js`, `backend/src/routes/public.js`, `backend/src/scripts/prune-logs.js`)**
   - ปรับ `publicApiLimiter` ใน `backend/src/server.js` จาก `120` เป็น `600` ครั้ง/นาที/IP รองรับกรณีบุคลากรออกอินเทอร์เน็ตผ่าน NAT IP เดียวกัน
   - ปรับ `feedbackLimiter` ใน `backend/src/routes/public.js` จาก `20` เป็น `60` ครั้ง/10 นาที/IP
   - ปรับสคริปต์ `backend/src/scripts/prune-logs.js` ให้ลบประวัติ `SearchLog` ที่เก่ากว่า `90` วัน (เดิม `180` วัน)
